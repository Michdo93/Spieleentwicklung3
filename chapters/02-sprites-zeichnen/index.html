Sprites zeichnen

Bilder laden und mit drawImage() zeichnen — in drei zunehmend nützlichen Varianten. Als Beispiel dient das echte Sprite-Sheet des Helden aus Ninja Fight, nicht ein abstraktes Platzhalterbild.

Ein Bild laden

Bilder werden über das Image-Objekt geladen — das Laden passiert asynchron, deshalb prüft man img.complete oder wartet auf das load-Event, bevor man zeichnet. 

const heroSheet = new Image();
heroSheet.src = "assets/hero.png";

heroSheet.addEventListener("load", () => {
  ctx.drawImage(heroSheet, 20, 10);
});

drawImage() in drei Formen

Je mehr Argumente, desto mehr Kontrolle. Alle drei Formen tauchen im fertigen Spiel wieder auf:

3 Argumente 
drawImage(img, x, y)
// Originalgröße, an
// Position (x,y)
5 Argumente 
drawImage(img,
  x, y, w, h)
// skaliert auf w×h
// 9 Argumente — nur einen Ausschnitt zeichnen
drawImage(img,
  sx, sy, sw, sh,   // Quellrechteck: WO im Bild
  dx, dy, dw, dh);  // Zielrechteck: WOHIN auf dem Canvas

Die 9-Argumente-Form ist die wichtigste für Sprite-Arbeit: Ein Sprite-Sheet ist ein einziges großes Bild mit vielen Postionen (Frames) nebeneinander — sx/sy/sw/sh schneiden genau einen Frame heraus, dx/dy/dw/dh bestimmen, wo und wie groß er auf dem Canvas landet. Kapitel 3 baut genau darauf eine komplette Animation.

Skalieren und positionieren

Da Quell- und Zielrechteck unabhängig sind, kann man ein Bild beliebig größer oder kleiner zeichnen, ohne die Bilddatei selbst zu verändern — in Demo 2 verändern zwei Regler nur dx/dw/dh.

Blickrichtung spiegeln

Ein Sprite nach links UND rechts zeigen zu lassen, ohne zwei separate Bilder zu brauchen: ctx.scale(-1, 1) vor dem Zeichnen spiegelt horizontal. Wichtig ist die Reihenfolge — erst zur gewünschten Position translate()n, dann scale()n, danach relativ zu (0,0) zeichnen. Das ist exakt die Technik, die drawNinja() in Ninja Fight für die Blickrichtung (facing) jeder Figur benutzt. 

ctx.save();
ctx.translate(x, y);       // 1. zur Position
ctx.scale(facing, 1);      // 2. spiegeln (facing: 1 oder -1)
ctx.drawImage(img, ..., -w/2, -h, w, h); // 3. relativ zu (0,0)
ctx.restore();
Bei Demo 3 auf "Spiegeln" klicken — dieselbe Figur, dieselbe Bilddatei, nur eine Zeile Code unterscheidet links von rechts.
