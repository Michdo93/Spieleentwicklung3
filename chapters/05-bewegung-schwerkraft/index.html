Bewegung & Schwerkraft

Kapitel 4 hat Tasten direkt in Position übersetzt (x += SPEED*dt). Für einen Sprung reicht das nicht — dieses Kapitel führt Geschwindigkeit als eigenen Wert ein und baut daraus exakt die Sprungphysik aus Hero.update().

Position vs. Geschwindigkeit

Solange sich etwas gleichmäßig bewegt, reicht x += SPEED * dt. Aber ein Sprung bremst sich selbst ab — die Geschwindigkeit ändert sich über Zeit. Dafür braucht man einen eigenen Wert für die Geschwindigkeit (vx/vy), den man selbst verändern kann, statt direkt die Position zu verschieben.

Nur Position (Kapitel 4) 
x += SPEED * dt;
// SPEED ändert sich nie
Geschwindigkeit als eigener Wert 
vx += BESCHLEUNIGUNG * dt;
x += vx * dt;
// vx wird selbst schneller

Schwerkraft: eine sich ständig erhöhende Fallgeschwindigkeit

Schwerkraft ist nichts Mysteriöses — nur eine Beschleunigung, die ständig nach unten wirkt. Zwei Zeilen erzeugen jeden Fall in diesem Tutorial und in Ninja Fight: 

vy += GRAVITY * dt;  // die Fallgeschwindigkeit nimmt zu
y  += vy * dt;       // die Position folgt der Geschwindigkeit

GRAVITY = 1400 (Pixel pro Sekunde²) ist derselbe Wert, der in Ninja Fight für Held und Gegner gilt — beide fallen exakt gleich schnell.

Der Sprung: negative Geschwindigkeit + Schwerkraft

Ein Sprung ist keine neue Physik — nur ein einmaliger Anstoß nach oben (negative vy, da "oben" auf dem Canvas kleinere Y-Werte bedeutet), auf den danach exakt dieselbe Schwerkraft wie in Demo 2 wirkt. Sie bremst die Aufwärtsbewegung, kehrt sie um, und der Sprung endet automatisch als Fall. 

if (key.jump && onGround) {
  vy = -JUMP_SPEED;   // einmaliger Anstoß nach oben
  onGround = false;
}
vy += GRAVITY * dt;    // wirkt immer, ob springend oder fallend
y  += vy * dt;

if (landung erkannt && vy >= 0) {  // nur beim FALLEN landen,
  y = boden; vy = 0; onGround = true;  // nicht beim Hochspringen
}

Die Bedingung vy >= 0 ist wichtig: Sie verhindert, dass die Figur "landet", während sie noch nach oben fliegt — man soll durch eine Plattform nach oben durchspringen können, aber beim Herunterfallen darauf landen. Genau diese Zeile steht auch in Hero.update().

Bei Demo 3 die Leertaste drücken, während der Kreis auf dem Boden steht (grün) — er springt (lila), fliegt einen Bogen, und landet von selbst wieder.
