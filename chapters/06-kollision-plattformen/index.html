Kollision & Plattformen

Kapitel 5 ist gegen einen fest einprogrammierten Bodenwert gesprungen. Ein echtes Level braucht mehrere Plattformen an unterschiedlichen Stellen — dieses Kapitel baut dafür exakt findLanding() aus Ninja Fight nach.

AABB: der einfachste Kollisionstest

"AABB" steht für Axis-Aligned Bounding Box — ein Rechteck, das nicht gedreht ist. Zwei solche Rechtecke überlappen sich genau dann, wenn sie sich auf beiden Achsen gleichzeitig überschneiden: 

function overlaps(a, b) {
  return a.left < b.right && a.right > b.left
      && a.top < b.bottom && a.bottom > b.top;
}

Das ist overlaps()/rectOf() aus render.js — dieselben zwei Funktionen prüfen im fertigen Spiel Schwert-Treffer, Projektil-Treffer und Gefahren-Kontakt. Ein einziger Test, überall wiederverwendet.

Landung: mehr als nur "überlappt gerade"

Für eine Plattform reicht "überlappt" allein nicht — sonst würde man auch von unten gegen die Plattform "landen". Man braucht zusätzlich: war die Figur im letzten Frame noch über der Plattform, und bewegt sie sich gerade nach unten (nicht nach oben)? 

function findLanding(nextY) {
  if (x > plattform.x && x < plattform.x + plattform.w  // horizontal drüber
      && y <= plattform.y + 2                              // eben noch drüber
      && nextY >= plattform.y) {                            // jetzt (fast) drauf
    return { y: plattform.y };
  }
  return null;
}

Das ist wortwörtlich Hero.findLanding() (und Enemy.findLanding(), identisch) aus Ninja Fight. Die Bedingung y <= plattform.y + 2 ist der Trick: sie stellt sicher, dass die Landung nur von oben erkannt wird.

Mehrere Plattformen: derselbe Test, in einer Schleife

Mit mehr als einer Plattform prüft man einfach jede einzelne und merkt sich die höchste (kleinster Y-Wert) unter den passenden — für den Fall, dass sich zwei Plattformen überlappen könnten.

Trefferbox ≠ Sprite

Wichtiges, oft übersehenes Detail: die für Kollision genutzte Box ist in Ninja Fight kleiner als das gezeichnete Sprite (Hero.width = 24, aber das Sprite wirkt deutlich breiter). Das fühlt sich beim Spielen fairer an — kleine Ungenauigkeiten beim Antippen einer Kante wirken dadurch nicht wie ein Bug.

Bei Demo 3 mit den Pfeiltasten über die drei Plattformen laufen und springen — die gestrichelte Box ist die tatsächliche Trefferbox, deutlich kleiner als der gezeichnete Kreis.
