Fernkampf & Projektile

Eine der dokumentierten Lücken im Original-Ninja-Fight: die Shuriken-Wurfanimation lief, aber es wurde nie ein tatsächliches Objekt erzeugt, das sich durch den Raum bewegt. Dieses Kapitel zeigt das Problem — und die Lösung.

Das Original-Problem: Animation ist nicht dasselbe wie ein Objekt

Ein naheliegender, aber trügerischer Ansatz: eine "Werfen"-Animation abspielen (Arm bewegt sich nach vorne) und denken, das sei der Wurf. Tatsächlich bewegt sich dabei gar nichts durch den Raum — die Animation zeigt nur eine Pose, kein Shuriken existiert als eigenständiges Ding, das man treffen oder verfehlen könnte.

Genau das war der reale Zustand im Original-Ninja-Fight (dokumentiert im "Known Bugs"-Dokument): doAction("Throw") lief, aber nirgends im Code stand new Shuriken(...).

Die Lösung: ein eigenständiges Objekt

Ein Projektil braucht seine eigene Position, seine eigene Geschwindigkeit, und eine eigene update()-Methode — unabhängig von der Figur, die es geworfen hat. Sobald es existiert, kümmert es sich selbst um seine Bewegung: 

class Projectile {
  constructor(x, y, dir) {
    this.x = x; this.y = y; this.dir = dir;
    this.speed = 480;
  }
  update(dt) {
    this.x += this.dir * this.speed * dt;
    if (this.x < -20 || this.x > STAGE_W + 20) {
      this.dead = true; // außerhalb der Bühne -> entfernen
    }
  }
}

Der Werf-Vorgang selbst wird dadurch simpel: die Angriffsanimation starten und zusätzlich ein neues Projektil-Objekt der Liste aller aktiven Projektile hinzufügen. Zwei getrennte Dinge, keine Vermischung.

Kollision: den eigenen Werfer ausschließen

Ein Projektil sollte nicht die Figur treffen, die es geworfen hat. In Ninja Fight speichert jedes Projektil eine Referenz auf seinen Werfer (this.owner) und prüft beim Kollisionstest alle anderen Figuren — das macht später sogar Friendly Fire zwischen mehreren Gegnern möglich, ohne Sonderfall-Code. 

update(dt, alleFiguren) {
  this.x += this.dir * this.speed * dt;
  for (const figur of alleFiguren) {
    if (figur === this.owner) continue; // eigenen Werfer überspringen
    if (überlappt(figur, this)) {
      figur.takeDamage(SCHADEN);
      this.dead = true;
    }
  }
}
Bei Demo 1 werfen und beobachten: nichts fliegt, nur eine Armbewegung. Bei Demo 2/3 entsteht ein tatsächliches Shuriken, das sich bewegt und (Demo 3) auch trifft.
