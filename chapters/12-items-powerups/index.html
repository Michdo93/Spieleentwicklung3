Items & Power-Ups

Ein Power-Up ist im Kern ein kleiner Cousin der Figuren aus den vorigen Kapiteln — es fällt mit derselben Schwerkraft, landet auf derselben Art Plattform, nur ohne eigene Steuerung.

Ein Item fällt genau wie eine Figur

Kein neuer Mechanismus nötig — PowerUp.update() verwendet exakt dieselbe Schwerkraft (Kapitel 5) und Landungs- Prüfung (Kapitel 6) wie Held und Gegner: 

class PowerUp {
  update(dt, plattformY) {
    this.vy += GRAVITY * dt;
    const nextY = this.y + this.vy * dt;
    if (nextY >= plattformY) {
      this.y = plattformY; this.vy = 0; this.landed = true;
    } else this.y = nextY;
  }
}

Drei Arten von Effekten

Nicht jeder Effekt funktioniert gleich. In Ninja Fight gibt es drei grundverschiedene Muster:

Sofortig (Herz) 
hp = Math.min(max, hp + 2);
// einmalig, keine Nachwirkung
Zeitbegrenzt (Schwert) 
hasSword = true;
swordTimer = 30;
// zählt selbst herunter,
// dann automatisch weg
// Zählbegrenzt (Shuriken)
shurikenCount += 3;
// nimmt bei jeder Nutzung ab,
// kein Timer nötig

Ein sofortiger Effekt braucht nichts weiter zu merken. Ein zeitbegrenzter Effekt braucht einen Timer, der jeden Frame herunterzählt. Ein zählbegrenzter Effekt braucht nur einen Zähler, der bei Benutzung sinkt — beide sind einfacher als sie klingen, sobald man sie als getrennte Muster erkennt.

Jeder kann es aufheben — auch der Gegner

Ein Detail, das leicht übersehen wird: PowerUp.update() prüft in Ninja Fight alle lebenden Figuren auf Kollision, nicht nur den Helden. Das bedeutet: ein Gegner kann dem Spieler ein Item buchstäblich vor der Nase wegschnappen, wenn er zuerst ankommt. 

for (const figur of [held, ...gegner]) {
  if (!item.collected && überlappt(figur, item)) {
    item.collected = true;
    figur.collectPowerUp(item.type); // wer zuerst da ist, gewinnt
  }
}
Bei Demo 3 mit den Pfeiltasten schneller sein als der (automatisch laufende) Gegner — wer zuerst am Schwert ist, bekommt es.
