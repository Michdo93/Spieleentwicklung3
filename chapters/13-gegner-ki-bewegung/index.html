Gegner-KI: Bewegung

Das Original-Ninja-Fight hatte für Gegner überhaupt keine KI — die Controller-Klassen waren leere Rümpfe. Die hier aufgebaute Patrouillenlogik mit Kantenerkennung war eine der Nacharbeiten, die erst beim tatsächlichen Testen des fertigen Spiels nötig wurden.

Der naheliegende erste Versuch: feste Grenzen

Ein Gegner soll patrouillieren — der einfachste Ansatz: zwischen zwei festen X-Koordinaten hin und her laufen. 

x += facing * SPEED * dt;
if (x <= patrolLeft)  { x = patrolLeft;  facing = 1; }
if (x >= patrolRight) { x = patrolRight; facing = -1; }

Das Problem: diese Grenzen wissen nichts von der tatsächlichen Plattform. Ist die Plattform kürzer als der Patrouillenbereich (oder steht der Gegner auf einer schmalen Plattform, die er selbst nie vermessen hat), läuft er einfach über die Kante. Genau das ist beim ersten Testen von Ninja Fight passiert — Gegner fielen viel zu oft von Plattformen herunter.

Die Lösung: vor jedem Schritt nach vorne schauen

Statt sich auf feste Grenzen zu verlassen, prüft der Gegner vor jeder Bewegung: ist ein Stück voraus (in Bewegungsrichtung) überhaupt noch Boden? Ist die Antwort nein, dreht er um, statt weiterzulaufen. 

function hasSupportAhead(lookAhead) {
  const aheadX = x + facing * lookAhead;
  return aheadX > plattform.x - 4
      && aheadX < plattform.x + plattform.w + 4;
}

if (!hasSupportAhead(26)) facing *= -1; // Kante! umdrehen
else x += facing * SPEED * dt;

Das ist wortwörtlich Enemy.hasSupportAhead() aus Ninja Fight. Der Clou: der Gegner braucht keine im Voraus festgelegten Patrouillengrenzen mehr — er erkennt die Kante der tatsächlichen Plattform von selbst, egal wie lang sie ist.

Springen, ohne die Kantenerkennung zu verlieren

Für ein lebendigeres Verhalten kann ein Gegner gelegentlich zufällig springen — aber nur, wenn hasSupportAhead() gerade "ja" sagt. Sonst würde ein zufälliger Sprung genau in dem Moment ausgelöst werden können, in dem der Gegner eigentlich gerade umdrehen sollte, und ihn doch über die Kante befördern.

Bei Demo 1 zusehen, wie der Gegner blind über die (kürzere) Plattform hinausläuft und fällt. Bei Demo 2/3 bleibt er zuverlässig auf der Plattform, egal wie lang sie ist.
