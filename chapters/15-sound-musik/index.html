Sound & Musik

Baut SoundController aus Ninja Fight nach: Hintergrundmusik, die je nach Spielzustand wechselt, kurze Soundeffekte, und eine gemeinsame Lautstärkeregelung für alles zusammen.

Musik: Menü und Spiel schließen sich gegenseitig aus

Zwei Audio-Objekte, eines für Menü-Musik, eines für Spiel-Musik — aber nie beide gleichzeitig. Jede play…Music()-Methode stoppt zuerst die jeweils andere: 

playMenuMusic() {
  this.gameMusic.pause();
  this.menuMusic.currentTime = 0;
  this.menuMusic.play();
}
playGameMusic() {
  this.menuMusic.pause();
  this.gameMusic.currentTime = 0;
  this.gameMusic.play();
}

Ohne das pause() der jeweils anderen würden beim Wechsel zwischen Menü und Spiel irgendwann zwei Musikstücke gleichzeitig laufen.

Soundeffekte: schnell hintereinander auslösbar

Ein Schwerthieb-Sound soll bei jedem Treffer neu starten — auch wenn der vorige Sound noch nicht zu Ende ist. Der Trick: currentTime vor jedem play() auf 0 zurücksetzen. 

playSword() {
  this.swordSfx.currentTime = 0; // von vorne beginnen
  this.swordSfx.play();
}

Ohne das würde ein zweiter Aufruf während des ersten Sounds nichts bewirken (der Sound spielt einfach weiter) oder abhängig vom Browser zu unerwartetem Verhalten führen.

Eine gemeinsame Lautstärke für alles

Ein einzelner Regler soll Musik und Soundeffekte gleichzeitig beeinflussen — dafür reicht es, jedem Audio-Objekt denselben Lautstärke-Wert zuzuweisen: 

changeVolume(v) {
  this.volume = v;
  [this.menuMusic, this.gameMusic, this.swordSfx, this.coinsSfx]
    .forEach(a => a.volume = this.volume);
}

Diese Einstellung greift erst beim nächsten play()-Aufruf für bereits pausierte Sounds, aber sofort für gerade laufende — genau das erwartet man von einem Lautstärkeregler.

Bei Demo 1 zwischen Menü- und Spielmusik wechseln — nie läuft beides gleichzeitig. Bei Demo 2 den Schwert-Sound mehrfach schnell hintereinander klicken.
