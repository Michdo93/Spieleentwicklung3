Menüs & Spielzustände

Baut ui.showScreen() aus Ninja Fight nach — und zeigt einen echten CSS-Bug aus der Entwicklung: eine gemeinsame Basisklasse verdunkelte versehentlich auch den Spielbildschirm selbst.

Mehrere Bildschirme, aber immer nur einer aktiv

Start-Menü, Pause, Einstellungen, Anleitung, Credits, das Spiel selbst — alles sind eigene HTML-Elemente, übereinandergelegt. showScreen(name) entfernt eine "aktiv"-Klasse von allen und setzt sie nur auf den gewünschten: 

function showScreen(name) {
  document.querySelectorAll(".screen")
    .forEach(s => s.classList.remove("active"));
  document.getElementById("screen-" + name)
    .classList.add("active");
}

Per CSS ist .screen standardmäßig display: none, .screen.active setzt display: flex — nie sind zwei Bildschirme gleichzeitig sichtbar.

Der echte Bug: eine Basisklasse trifft den falschen Bildschirm mit

In Ninja Fight hatte die .screen-Basisklasse einen abdunkelnden Verlauf als Hintergrund — gedacht für die Menü- Bildschirme, damit Text über dem Hintergrundbild lesbar bleibt. Das Problem: jeder Bildschirm bekommt diese Klasse, auch #screen-game — der während des Spiels direkt über dem Canvas liegt. Das ganze Spielfeld wirkte dadurch dauerhaft abgedunkelt.

Fehlerhaft 
.screen {
  background: linear-gradient(
    dunkel, dunkler);
}
/* gilt für ALLE .screen-Elemente,
   auch #screen-game */
Korrigiert 
#screen-game {
  background: none;
}
/* ID-Selektor gewinnt gezielt
   gegen die Basisklasse */

Die Korrektur nutzt aus, dass ein ID-Selektor immer eine höhere Spezifität hat als ein Klassen-Selektor — #screen-game überschreibt .screen zuverlässig, unabhängig davon, welche zusätzlichen Klassen das Element sonst noch trägt.

ESC als universeller Pause-Schalter

Ein Tastatur-Listener auf Escape ruft pauseGame()/resumeGame() auf — dieselbe Zustandsmaschine wie bei Button-Klicks, nur über die Tastatur ausgelöst statt über die Maus.

Bei Demo 2 auf "Bug umschalten" klicken — das Canvas-Ersatzfeld (grün-braun gestreift) wird plötzlich abgedunkelt, obwohl gar kein Menü-Bildschirm gemeint war.
