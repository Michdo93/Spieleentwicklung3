Highscores & Levelfortschritt

Das letzte Kapitel: Ergebnisse dauerhaft speichern, die Bedingungen für Sieg und Niederlage — und wie alle 17 vorigen Kapitel zusammen ein vollständiges Spiel ergeben.

Highscores, die einen Seitenneuladen überstehen

localStorage speichert Text-Daten dauerhaft im Browser — auch nach dem Schließen des Tabs. Für eine Highscore- Liste reicht ein Array aus Objekten, als JSON gespeichert: 

function saveHighscore(name, points, level) {
  const list = JSON.parse(
    localStorage.getItem("highscores") || "[]");
  list.push({ name, points, level });
  list.sort((a, b) => b.points - a.points);
  localStorage.setItem("highscores",
    JSON.stringify(list.slice(0, 10))); // nur Top 10 behalten
}

Ninja Fight ersetzt damit den ursprünglichen PHP-Server des Originalspiels — GitHub Pages kann kein PHP ausführen, localStorage braucht dafür aber auch gar keinen Server.

Sieg oder Niederlage — mehr als nur "tot oder nicht"

Ein Spieldurchlauf endet nicht nur durch Sterben. In Ninja Fight gibt es mehrere Wege zur Niederlage und genau einen Weg zum Sieg: 

if (!heldLebt) return "Niederlage: gestorben";
if (zeitAbgelaufen && gegnerÜbrig > 0)
  return "Niederlage: Zeit abgelaufen, Gegner übrig";
if (levelNum >= maxLevel)
  return "Sieg: alle Level geschafft";
return "Spiel läuft weiter";

Wichtig: "Zeit abgelaufen" allein ist keine Niederlage — nur in Kombination mit noch lebenden Gegnern. Ohne Gegner ist ein Zeitablauf einfach der normale Übergang zum nächsten Level.

Alles zusammen: kumulative Lebenspunkte

Ein schönes Beispiel dafür, wie mehrere frühere Kapitel zusammenspielen: Level-Fortschritt (dieses Kapitel), Schaden (Kapitel 10), und der Game-State selbst ergeben zusammen die Formel, die in GameManager.nextLevel() steht: 

this.lifeEnergy += 10 * this.levelNum;
// NICHT: this.lifeEnergy = 10 * this.levelNum;

Der Unterschied zwischen += und = ist hier alles: mit = würde jeder Levelaufstieg die Lebenspunkte komplett zurücksetzen (verlorene HP aus dem letzten Level wären egal) — mit += zählt der Fortschritt über das gesamte Spiel hinweg.

Das war's — alle 18 Kapitel zusammen ergeben ein vollständiges, spielbares Ninja-Fight-Spiel. Schau dir jetzt gerne das fertige Repo NinjaFight an und vergleiche es mit dem, was du hier Schritt für Schritt gebaut hast.
